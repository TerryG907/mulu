# Fixtures/regression

Committed test inputs: one reproducer per finding of the adversarial reviews (see
[docs/RESULTS.md](../../docs/RESULTS.md)). `tools/run_all.sh` verifies every one of them on each run;
nothing here is ever regenerated by the test run.

**Many of these PDFs are deliberately malformed or hostile**: a decompression bomb that inflates to
256 MB, a catalog nested 100,000 levels deep, a chain of 20,000 `/DecodeParms` dictionaries, broken
cross-reference tables and junk before `%PDF-`. They exist to prove that mulu refuses or handles them
safely. Do not open them in PDF viewers or other PDF libraries; some of those libraries crash on them.

- `manifest.json` is the index: for each fixture it records the finding, where the file came from and
  the options `tools/verify/verify.py` applies.
- Sidecars per fixture: `<name>.toc.txt` (the outline to write), `<name>.expected.json` (what every
  reader must report), an optional `<name>.expect` (`refuse`) and optional `.reapply.*` files.
- The files are byte-exact inputs; `.gitattributes` keeps git from converting their line endings.
- `tools/fixtures/make_regression.py` documents how the set was assembled.
